学习笔记

每天学的东西，整理成笔记自动同步到 GitHub。

起因

自学电脑知识最大的问题是"学了就忘"。想养成每天记录的习惯：当天学了什么、踩了什么坑、结论是什么，写下来，以后能翻回去看。

方案与实现

流程：每天的学习内容记在本地笔记里 → 定时任务在每天 0 点整理前一天的笔记 → 去掉隐私内容（脱敏）→ 写入仓库 daily/ 目录 → 自动 push 到 GitHub。

仓库：Final-FSY/learning-notes（公开），README 里有索引，方便按日期翻。

传输：GitHub 直连不稳定，用了 SSH 443 端口通道，实测稳定。

内容：目前包括 Linux 系统管理、家庭网络、越狱开发、建站等主题，每篇都记录具体命令、参数和踩坑结论，尽量写成"下次照着做就能成功"的程度。

踩过的坑

· 写脚本时，含密码/token 的内容可能被工具脱敏成占位符，导致登录脚本 401，要用已知正确的文件对照修复；

· GitHub 直连间歇性超时，需要走代理或换端口；

· 笔记发布前要检查隐私：内网 IP 没问题，但密码、token、地址电话绝对不能出现。

现状

每日自动同步运行中，笔记在持续积累。
