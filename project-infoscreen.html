家庭信息屏

用一台越狱的 iPhone 6s Plus 改造成的家庭信息面板。

起因

家里缺一个"一抬头就能看到"的信息面板：时间、天气、今天的新闻、家里人的留言。买现成的信息屏不便宜，正好手头有一台闲置的 iPhone 6s Plus，决定自己动手。

方案与实现

设备：iPhone 6s Plus（iOS 15.8），palera1n 越狱，TrollStore 安装应用。

应用：Theos 工具链开发的原生 Objective-C 应用（在树莓派上交叉编译）。功能包括：

· 大字时钟，每秒刷新；

· 日期与天气卡片（Open-Meteo 免费接口，直连涿州数据）；

· 新闻 5 条（RSS 源：少数派、果壳、BBC 中文）；

· 家庭备忘录；电量显示；固定竖屏深色主题；隐藏状态栏。

数据服务：一个零依赖的 Python 服务（只用标准库），每 10 分钟抓一次天气和新闻，加上备忘录内容，聚合成一个 data.json，手机 App 通过 HTTP 读取。最初计划放在 Orange Pi 上，后来 Orange Pi 转职成了电视盒子，服务就挪到了常开的树莓派上（:8081，现在每天都自动更新名言/科普/备忘录内容）。

图标：用 Python PIL 脚本生成 18 个尺寸的深底白时钟图标。

踩过的坑

· Theos 在 Linux 上必须单独装工具链（clang 等），否则编译报路径不存在；

· GitHub 下载 SDK 直连间歇性超时，最后走了 gh.ddlc.top 代理才稳定；

· 图标生成要放到项目 Resources 目录，生成到编译产物目录会被覆盖；

· 下载脚本要支持断点续传（curl -C -），否则大文件下到一半就失败。

现状与下一步

App 已编译打包（.ipa 和 .deb）；数据服务已在树莓派上常驻运行，内容每日自动更新。

待办：天气刷新频率调优、扩充新闻源。
