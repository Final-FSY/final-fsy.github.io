关于我

范小皮，15 岁，河北保定人。开学后就读于保定市爱和城高级中学。

表面上是普通中学生，背地里是个电脑折腾爱好者。家里的树莓派、Orange Pi、路由器都被我改造过：全屋 DNS 广告拦截、家庭信息屏、手机遥控电视……全靠自学 + 踩坑，经验都是坑里爬出来的，笔记都记在 GitHub 上。

除了电脑，我还有三样爱好：

📷 摄影——喜欢到处拍

🏃 运动——出出汗才舒服

🎻 小提琴——有六级证书，虽然上了初三以后就没怎么碰过
