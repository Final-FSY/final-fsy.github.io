这个网站

0 元预算拥有自己的域名和网站。

起因

想要一个自己的网站和域名，但不想花钱。域名和托管都有免费方案：eu.org 提供免费域名（1996 年至今，非营利运营），Cloudflare 提供免费的 DNS、托管、HTTPS 证书和 CDN。

方案与实现

域名：eu.org 申请 finalfsy.eu.org（免费，个人非商业用途）。申请需要提供两个有效的 nameserver，正好用 Cloudflare 的（darwin / vivienne.ns.cloudflare.com）。eu.org 会自动检查 nameserver 的 SOA 和 NS 记录，全部通过后才进入人工审核。

托管：Cloudflare Pages 免费套餐，直接把静态文件上传即可，自带全球 CDN 和自动 HTTPS。

前端：手写 HTML/CSS/JS，深色主题 + 虾橙配色，公共样式抽成 style.css 供多页面复用；照片用 ffmpeg 压缩到适合网页的尺寸；页面做了响应式适配（电脑/iPad/手机）。

概念：通过这个项目弄懂了域名、DNS（电话簿）、托管、备案（海外免费方案不需要）之间的关系。

踩过的坑

· eu.org 账号注册邮箱不能用 Gmail（官方明确警告验证邮件会被拒收）；

· 申请时 nameserver 必须真实有效，eu.org 会实际发查询验证，填错会被拒；

· 审核是人工的，没有固定时间，反复提交只会更慢；

· 浏览器缓存会显示旧版本，改完文件要强制刷新（Ctrl+F5）；

· 图片不压缩直接传会导致页面加载慢，需要先调整尺寸。

现状与下一步

网站内容基本就位，域名还在等 eu.org 人工审核（已提交，技术检查全绿）。

批下来后：Cloudflare 绑定域名 → 部署到 Pages → 正式上线。
